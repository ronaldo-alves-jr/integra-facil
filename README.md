# 🏡 Integra Fácil - Imóveis

Aplicação web para exibição de imóveis para locação, com dados coletados automaticamente via web scraping.

---

## 📌 Sobre o projeto

O **Integra Fácil - Imóveis** é uma aplicação desenvolvida com o objetivo de facilitar a visualização de imóveis disponíveis para aluguel. Os dados são coletados automaticamente de sites imobiliários e exibidos em uma interface simples e intuitiva.

---

## ⚙️ Funcionalidades

- 🔍 Busca de imóveis por bairro
- 🏷️ Exibição de preço
- 🖼️ Listagem com imagens
- 📊 Contador de imóveis encontrados
- 📡 Integração com múltiplas fontes de dados

---

## 🧠 Tecnologias utilizadas

### Frontend
- HTML5
- CSS3
- Bootstrap
- JavaScript

### Backend
- Node.js
- Express

### Banco de dados
- SQLite

### Web Scraping
- Python
- Selenium
- BeautifulSoup

---

## 🔄 Como funciona

1. Um script em Python realiza a coleta de dados de sites imobiliários
2. Os dados são armazenados em um banco SQLite
3. O frontend consome esses dados e exibe os imóveis
